# Profile repository setup

- `README.md` is the GitHub profile landing page.
- The `projects/employee-tracker/` folder contains a small Python + CSV demo.
- Run the tracker from its folder with `python employee_tracker.py list`.
- The dashboard uses third-party GitHub README statistics services; they may occasionally be unavailable.

Only publish synthetic or anonymized data. Never commit real employee records, Iqama/passport numbers, bank details, private contact details, or company-confidential information.
