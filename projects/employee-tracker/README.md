# Employee Tracker (Demo Project)

A small command-line project for learning Python and CSV data handling. It uses synthetic sample records only.

## Features
- List demo employees
- Search by employee ID or name
- Add a demo employee to a local CSV file

## Requirements
- Python 3.9+
- No third-party packages required

## Run
From this folder:

```bash
python employee_tracker.py list
python employee_tracker.py search EMP002
python employee_tracker.py add EMP004 "Sam Demo" "Operations"
```

The script reads and writes `employees.csv` in this folder. Sample records are fictional. Never publish real employee records or sensitive personal information.
